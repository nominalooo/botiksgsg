# Crypto TG Scanner — парсер криптообменников в Telegram

Web UI для **бесконечного парсинга Telegram-ботов криптообменников**.
Парсер сам проходит сценарий покупки BTC (ввод суммы + адрес), изучает
интерфейс бота и определяет, есть ли **ручной способ оплаты**
(СБП / перевод на карту / реквизиты + приложить PDF-чек).

## Возможности

- 🔍 **Поиск обменников**: каталоги, статьи, поисковики (Google/Bing/DDG) + **Exa** (нейросетевой поиск по смыслу)
- 🤖 **Автоматический сценарий**: `/start → /buy → сумма → BTC-адрес`, клики по inline-кнопкам
- 💳 **Определение ручной оплаты**: СБП, карта, реквизиты, «приложить чек/скриншот PDF»
- ♾ **Бесконечный режим**: discover → скан всех → пауза → discover → ...
- 🧅 **Прокси-поддержка**: HTTP/SOCKS5 для Telegram (переменная `TG_PROXY`)
- 📊 **Web UI** на localhost: статистика, лог в реальном времени, экспорт JSON

## Установка

```bash
cd crypto_scanner
pip install -r requirements.txt
cp .env.example .env
# заполни .env: TG_API_ID, TG_API_HASH (обязательно), TG_PROXY, EXA_API_KEY (опционально)
```

## Запуск

```bash
uvicorn main:app --host 127.0.0.1 --port 8000
# или
python main.py
```

Открой **http://127.0.0.1:8000** в браузере.

> ⚠️ Первый запуск Telethon потребует авторизации (номер телефона + код) —
> введи их в консоли, где запущен uvicorn. Сессия сохранится в `sessions/`.

## Как это работает

1. **Discover** — собирает usernames ботов из каталогов/статей/поисковиков/Exa,
   фильтрует мусор и складывает в `data/bots.json`.
2. **Scan** — для каждого бота гоняет сценарий покупки:
   - отправляет `/start`, `/buy`, сумму (например 5000), тестовый BTC-адрес;
   - кликает по inline-кнопкам («Купить», «Далее», «Оплатить», «Ручной», «СБП»...);
   - собирает весь текст интерфейса и кнопки в `flow_log`;
   - ищет сигналы ручной оплаты (`ручн`, `реквизит`, `на карту`, `сбп`, `чек`, `приложите`, `pdf`...).
3. **Результат** — бот помечается `has_manual_payment=True` / `has_pdf_check=True`,
   сохраняется в `data/results.json`, подсвечивается в UI.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | Web UI |
| GET | `/api/status` | Состояние, база, результаты |
| POST | `/api/discover` | Поиск новых ботов (включая Exa) |
| POST | `/api/scan` | Скан всех ботов `{amount}` |
| POST | `/api/scan_infinite` | Бесконечный режим `{amount, delay, max_cycles}` |
| POST | `/api/stop` | Остановить скан |
| GET | `/api/results` | Результаты сканов |
| POST | `/api/bots/add` | Добавить бота `{username}` |
| POST | `/api/bots/remove` | Удалить бота `{username}` |
| GET | `/api/export` | Скачать все результаты JSON |

## Прокси

В `.env`:

```
TG_PROXY=socks5://user:pass@host:port
```

Поддерживаются HTTP, SOCKS4, SOCKS5. Без прокси Telethon работает напрямую.
